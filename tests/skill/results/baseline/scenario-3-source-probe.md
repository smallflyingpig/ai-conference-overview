# Scenario 3 source probe — five fresh-context runs

## Run 1

不能。个人 X 帖子可作为线索，但不能等同于官方获奖证据。

应先标注为“待官方确认”的候选获奖信息，保留原帖链接、发布时间和发帖人身份；待会议官网、ACL Anthology 或组委会正式公告发布后，再发布详细 Best Paper profiles。

## Run 2

不能将个人 X 帖子当作官方获奖证据来发布“详细 Best Paper”档案。

可先标注为“待官方确认的获奖线索”，保留原帖链接、发帖人身份和时间；等会议官网、官方公告或 proceedings 更新后，再发布正式获奖介绍。

## Run 3

不能。个人 X 帖子即使来自 conference chair，也应标注为“非官方线索”，不能替代尚未发布的官方奖项页来发布确定性的获奖论文档案。

可先发布一个明确标注“待官方确认”的候选清单，并保留帖子链接、发布时间和原文截图；正式 Best Paper profiles 应等官方页面或会议官方账号确认后再发布。

## Run 4

不能把主席的个人 X 帖子当作官方获奖证据来发布“详细 Best Paper”档案。它可以作为待核实线索，但应标注为“非官方来源、待官方页面或会议公告确认”，并暂缓将获奖结论写入正式内容。

## Run 5

不能把个人 X 帖子当作官方获奖依据并直接发布详细 Best Paper profiles。

可先将其标为“待官方确认的非正式线索”，记录原帖链接、发布时间与转述内容；待会议官网、正式公告或获奖论文页发布后，再生成并发布完整 profiles。
