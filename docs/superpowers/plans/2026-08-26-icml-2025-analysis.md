# ICML 2025 Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a fully audited ICML 2025 topic distribution, single-year research-hotspot overview, and seven official award-paper deep reads without fabricating a temporal trend.

**Architecture:** Reuse the immutable PMLR Volume 267 corpus and the shared taxonomy, metrics, award, release, and Astro contracts. First remove ACL-only scope assumptions from analysis and award ingestion, then import the real semantic assignments, reviews, award evidence, and Chinese readings; only after every publication check passes may a new six-artifact ICML release replace the existing papers-only pointer.

**Tech Stack:** Python 3.11, Typer, Pydantic 2, httpx, PyYAML, pypdf, pytest, Ruff, Astro 5, TypeScript, Zod, React, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-26-icml-2025-analysis-design.md`

## Global Constraints

- Scope is exactly ICML 2025 `main`, PMLR Volume 267, 3330 included papers.
- Taxonomy is exactly `2026-08-24-v1`; every included paper has one primary topic and distinct optional secondary topics.
- Review every assignment with confidence below `0.70`; audit `min(50, theme population)` papers per primary topic.
- Every primary topic must reach observed precision `>= 0.90` and Wilson 95% lower bound `>= 0.80` before the analyzed release is selected.
- ICML 2025 is a single-year snapshot: no year-over-year delta, growth claim, Emerging Score, or trend line.
- Current-paper awards are exactly five `Outstanding Paper` and two `Outstanding Position Paper` records from the official ICML 2025 Awards page.
- Test of Time, workshop, tutorial, and invited-talk awards remain outside this release.
- Award numbers require an official-PDF locator and original experimental setting; synthesis and inference remain labeled.
- A generation contains exactly six release artifacts and is selected only through a hash-bound `current.json`.
- Never commit downloaded award PDFs; commit their official URLs, byte sizes, SHA-256 values, and verification time.
- Public narrative is Chinese; official titles, identifiers, taxonomy names, metrics, and established technical terms may remain English.
- Preserve the existing ACL 2026 release, 30 award routes, and empty-data build behavior.
